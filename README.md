# Airline Performance & Delay Analysis

## Overview
Engineered a high-performance BI solution analyzing over 2 million flight records to pinpoint delay root causes. The dashboard gives granular insights into carrier reliability, weather impacts, and airport bottlenecks to support operational decisions.

## Key Features
- Analysis of 2M+ flight records
- Delay root-cause analysis by carrier, weather, and airport
- Star Schema data model
- ETL with Power Query

## Tech Stack
Power BI, Power Query, DAX, Data Modeling (Star Schema)

## Skills Demonstrated
- Data modeling (Star Schema)
- ETL with Power Query
- DAX measures
- Operational performance analysis
